# Sheetwise

Print on less paper: put 2, 4 or 8 pages on one sheet, make booklets, add page tags,
letterheads and notes, then send the result to your real printer.

Sheetwise works as a **printer**. On Windows it installs a printer named **Sheetwise**; on a Mac
it appears in every Print dialog under **PDF → Sheetwise**. Whatever you print there opens in
Sheetwise, where you arrange it and print it to your normal printer (or save it as a PDF).

## How it works

1. **Print** from any program to the *Sheetwise* printer (Mac: *File → Print → PDF → Sheetwise*).
2. Sheetwise **opens by itself** with the print job. On Windows a small Task Scheduler entry
   starts it when the job has been printed; nothing runs in the background between print jobs.
3. **Choose a layout** and options on the left; the sheet preview updates as you go.
4. **Print** (or **Print & Close**) to the destination printer. Sheetwise quits after printing a
   job it was opened for.
